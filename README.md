# Картина дня — Кишинёв

Личный дашборд: курс USD/EUR, цены на бензин/дизель (ANRE), тарифы ЖКХ
(вода, отопление, газ, электричество). Обновляется раз в сутки через
GitHub Actions, публикуется на GitHub Pages.

## Как запустить

1. Создай пустой репозиторий на GitHub, залей туда содержимое этой папки:
   ```
   git init
   git add .
   git commit -m "Скелет дашборда"
   git branch -M main
   git remote add origin <ссылка на твой репозиторий>
   git push -u origin main
   ```
2. В Settings → Actions → General убедись, что Actions разрешены,
   и что у workflow есть право на запись (Settings → Actions → General →
   Workflow permissions → **Read and write permissions**) — без этого
   бот не сможет закоммитить обновлённые данные.
3. Запусти workflow вручную первый раз: вкладка **Actions** →
   **Update dashboard** → **Run workflow**. Он соберёт данные и
   сгенерирует `docs/index.html`.
4. Включи Pages: Settings → Pages → Source: **Deploy from a branch**,
   Branch: **main**, папка **/docs**. Через минуту страница появится
   по ссылке вида `https://<юзернейм>.github.io/<репозиторий>/`.
5. Дальше всё само: cron в `.github/workflows/update.yml` гоняет
   обновление каждый день в 15:00 UTC.

## Структура

```
data/               — накопленная история (JSON, append-only)
scripts/
  fetch_currency.py — курс USD/EUR с НБМ
  fetch_fuel.py      — цены на бензин/дизель с ANRE
  fetch_utilities.py — тарифы ЖКХ с ANRE
  build_site.py      — собирает docs/index.html из data/*.json
docs/                — сгенерированная страница (появится после первого запуска)
```

## Что нужно проверить перед тем, как доверять данным

- **Газ и электричество** в `fetch_utilities.py` — операторы и колонки
  (`operator_match` / `value_col_match`) подобраны предварительно:
  таблицы ANRE по этим двум категориям сложнее (много операторов,
  тарифных зон и категорий обслуживания). После первого прогона
  сверь вывод скрипта в логе Actions с реальной таблицей на
  соответствующей странице ANRE и поправь при расхождении.
- **Вода/отопление** — проверены вручную, должны работать сразу
  (оператор — Apă-Canal Chişinău и Termoelectrica).

## Логика "риска" (красная строка)

- Для курса и топлива — честная: если последние 5 точек истории
  подряд растут или падают, показывается пометка риска. Никакой
  интерпретации новостей.
- Для тарифов ЖКХ — пока не реализовано (следующий шаг): планируется
  сверяться со списком поданных заявок на пересмотр тарифа на сайте
  ANRE (`Proiecte supuse aprobării`), а не с журналистскими
  прогнозами.
